# FREINDLY HOUSEHOLD PLANTS🪴🪴🪴
## Welcome to the page of household plants ##
The purpose of this website is to helping people to find
safe and easy-to-care for indoor plants.

The main moto of this project is to helping new plant owners 
to avoid toxic plants.

 [Visit Freindly Household plants](https://github-practice-silk.vercel.app/)

**Features:**
- A searchable database of non toxic plants.
- Care instructions(watering,light requirements,best for,etc.)for each plant.
